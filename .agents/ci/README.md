# `.agents/ci` — CI Status & Telemetry

This directory contains current-run quality telemetry and generated local
summaries. GitHub Actions publishes status and quality summaries as downloadable
artifacts and writes the readable summary to the workflow run; default CI does
not commit generated files back to project branches.

## Files

| Path | Kind | Content |
|---|---|---|
| `ci-status.json` | Status | Consolidated result of the current CI run (`QualityReport`), uploaded as a workflow artifact. |
| `ci-summary.md` | Status | Human-readable Markdown rendition of the current run's status, uploaded as a workflow artifact and added to the job summary. |
| `quality-run.json` | Telemetry | Schema-versioned telemetry for the last run: tier, plan source, scope, per-stage timing/skip reasons, toolchain versions (see `schema/ci-telemetry.schema.json`). Uploaded as a GH Actions artifact, not committed. |
| `quality-summary.md` | Telemetry | Readable summary of `quality-run.json`, also appended to the job summary. |

## Lifecycle

The `ci-success` job creates the status files from the current workflow run and
uploads them without repository write access. `quality-run.json` and
`quality-summary.md` are generated by `xtask`, uploaded by the quality-gate job,
and are not committed (see `.gitignore`).

## Disabling telemetry

Set `enabled = false` in `config/ci/telemetry.toml` to stop emitting the
quality telemetry pair. The workflow status artifacts and job summary remain
available.
